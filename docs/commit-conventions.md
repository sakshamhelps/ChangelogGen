# How commits are mapped

| Subject | Section |
|---|---|
| `feat: ...` | Added |
| `fix: ...` | Fixed |
| `perf: ...` | Performance |
| `refactor: ...` | Changed |
| `docs: ...` | Documentation |
| `type!: ...` or body contains `BREAKING CHANGE` | Breaking Changes |
| anything else | Other |
| `chore/ci/build/test/style` | hidden (use `--include-chore`) |
